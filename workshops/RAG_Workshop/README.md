# LLMs Beyond Prompting: Improve LLMs with RAG Workshop

## Workshop Overview
This 4-hour workshop introduces Retrieval-Augmented Generation (RAG) for beginners. RAG enhances Large Language Models (LLMs) by retrieving relevant information from external knowledge sources before generating responses, improving accuracy and reducing hallucinations.

### Schedule
- **Hour 1:** Slides presentation on RAG fundamentals
- **Hours 2-4:** Hands-on labs and final challenge (each ~45-60 minutes)

### Prerequisites
- Basic Python knowledge
- Python 3.8+
- Install required packages: `pip install sentence-transformers faiss-cpu langchain transformers langchain-huggingface pypdf pytube`

### Labs (Jupyter Notebooks)
1. **Lab 1: Embeddings and Vector Databases** - Learn to create embeddings and store/query them.
2. **Lab 2: Basic RAG Pipeline** - Build a simple RAG system with data ingestion.
3. **Lab 3: Advanced RAG Techniques** - Experiment with chunking and multi-source data.

### Final Challenge
Build a comprehensive RAG application with interactive Q&A.

All labs use free HuggingFace models (no API keys needed). Includes data ingestion from PDFs, webpages, and YouTube. Each notebook has tutorials, exercises, and discussions.
